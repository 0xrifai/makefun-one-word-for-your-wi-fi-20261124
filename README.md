## The word

**Liar.**

Home Wi-Fi's most recognisable lie is showing full signal while nothing
loads. It claims to be connected and then does nothing — it looks you in the
eye and lies. One word, four letters, funny the instant you read it, and
true of every home network that has ever shown full bars on a dead page.

## Run it

Requires Node 22.18 or later (the grader runs Node 22.23.4). No network, no
secrets, no dependencies to install.

```sh
node main.ts
cat /output/entry.txt   # Liar
```

The program writes exactly `Liar` — four characters, no trailing newline —
to `/output/entry.txt`, deterministically, on every run.
